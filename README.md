Веб-застосунок для конвертації Excel файлів (.xls, .xlsx) у JSON формат з попереднім переглядом даних.

Технології: Java, Spring Boot, Spring MVC, Thymeleaf, Apache POI, Jackson, JUnit 5

Основний функціонал:

Завантаження Excel файлів через веб-інтерфейс
Попередній перегляд даних (Thymeleaf)
Конвертація Excel → JSON з можливістю завантаження
Підтримка декількох sheet

Реалізовано:

Автоматичне визначення header (навіть якщо не в першому рядку)
Обробка різних типів даних (String, Number, Boolean, Date, Formula)
Генерація унікальних назв колонок
Обробка порожніх значень та некоректних файлів
Exception handling (custom exception)

Тестування:

Unit-тести (JUnit 5) для перевірки:
парсингу даних
обробки дат і формул
edge-case сценаріїв

Результат:

Перетворення Excel у структурований JSON (List<Map<String, Object>>)
Готовий до інтеграції з REST API або frontend
